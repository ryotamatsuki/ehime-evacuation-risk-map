# 愛媛県「南海トラフ・本当に逃げられるかマップ」

愛媛県沿岸14市町を対象に、人口、津波浸水曝露、避難場所までの徒歩距離、避難経路の津波浸水曝露、避難場所の想定収容人数を重ね合わせ、500mメッシュ単位で避難困難度を探索するWebGISです。

## 現在の状態

このコミットは、前回作業で報告された中間成果を失わないための再開チェックポイントです。前回の実行環境に生成された詳細ファイルは現在の作業環境へ引き継がれていないため、集計値は `data/qa/shelter_join_report.csv` と `data/metadata/progress_checkpoint.json` に「前回報告値」として記録しています。個別メッシュ、ルート、津波曝露、容量負荷の架空データは作成していません。

## 前回報告で確認された中間成果

- 沿岸14市町の500m人口メッシュ：5,947件
- 避難場所属性：愛媛県XLSX 1,973施設
- 座標結合：common_id一致1,891件、名称・住所一致54件、未照合26件、重複2件
- 人口の秘匿・欠損値：0補完せず、null／品質フラグを保持
- 次工程：津波タイルの500m集計

## 予定する構成

- `scripts/`: 再現可能なデータ取得・加工・検証コード
- `public/data/`: Web表示用の加工済みデータ
- `src/`: React + TypeScript + Vite + MapLibre UI
- `data/qa/`: 結合・数値・GIS検証レポート

## 重要な制約

- 2026年愛媛県地震被害想定GISの271MB ZIPは格納しない。
- 欠損値、秘匿値、未照合施設を推測値で補完しない。
- OSMは歩行ルーティングに使用するが、ネットワーク全量を公開配信しない。
- 避難困難度の重みはPoC用探索的重みであり、公式の政策基準ではない。

## 免責

本サイトは公開データを用いた政策分析・可視化PoCです。実際の避難行動や避難経路の安全を保証するものではありません。愛媛県の最新津波浸水想定は2025年9月2日に変更されています。災害時及び詳細な防災判断には、愛媛県・各市町等が公表する最新の防災情報・ハザードマップを確認してください。
