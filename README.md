# 愛媛県「南海トラフ・本当に逃げられるかマップ」

愛媛県沿岸14市町を対象に、人口、津波浸水曝露、避難場所までの徒歩距離、避難経路の津波浸水曝露、避難場所の想定収容人数を重ね合わせ、500mメッシュ単位で避難困難度を探索するWebGISです。

## 予定する構成

- `scripts/`: 再現可能なデータ取得・加工・検証コード
- `public/data/`: Web表示用の加工済みデータ
- `src/`: React + TypeScript + Vite + MapLibre UI
- `data/qa/`: 結合・数値・GIS検証レポート

## スコアの読み方

津波浸水曝露25、要配慮人口20、徒歩アクセス25、経路津波曝露15、避難場所収容負荷15を初期値とする0–100の探索的スコアです。徒歩アクセスは分析範囲内のネットワーク距離を5–95パーセンタイルで正規化し、容量負荷は仮割当人口／想定収容人数が1.0で100点に達するようにしています。公式の政策基準ではありません。欠損要素は利用可能な重みで再正規化し、`data_completeness`を別表示します。

## 再実行とQA

```bash
npm run build
```

OSM歩行ネットワークのGraphMLと津波タイルキャッシュはローカル中間データです。公開リポジトリには自治体別の加工済みメッシュ、リスク、ルート、避難場所データだけを格納します。

## 重要な制約

- 2026年愛媛県地震被害想定GISの271MB ZIPは格納しない。
- 欠損値、秘匿値、未照合施設を推測値で補完しない。
- OSMは歩行ルーティングに使用するが、ネットワーク全量を公開配信しない。
- 避難困難度の重みはPoC用探索的重みであり、公式の政策基準ではない。
